§17 · For technical diligence — the process is the asset

How we build: evidence-driven engineering.

01

Re-run, never trust

Every session re-verifies prior claims with literal command output. Twice this caught "done" items that had never reached main — and completed them for real.

02

Falsify before you claim

Each migration's new tests must FAIL against the old code (stash test) before acceptance. In PR #29: 63 of 70 new tests failed on old code — proof they test real behavior.

03

Ratchets, not promises

Quality floors live in CI: money adoption, toFixed count, type-safety, docs-truth. They can tighten, never loosen, without deleting a guard — a visible act in review.

§19 · Appendix A

Glossary of terms.

FP&A

Financial Planning & Analysis — budgeting, forecasting, consolidation, reporting and decision support for the CFO office.

Engine

A dedicated, tested calculation module (e.g. LoanAmortizationEngine). 190 top-level engines; 183 shipped and reachable.

Money primitive

src/utils/money.ts — the canonical decimal (decimal.js) API for currency math: ROUND_HALF_UP, exact sums, deterministic penny allocation, strict errors.

Ratchet

A CI guard whose baseline can only tighten, never loosen (decimal-adoption floor, raw-rounding ceiling).

Falsification

Proving a new test has value by showing it FAILS against the old code before the fix is accepted.

Gap ledger

GAP_LEDGER.md — the public, evidence-backed register of every known gap, decision and exclusion.

IEEE-754 / float drift

Ordinary binary floating-point, which cannot represent most decimals exactly (0.1 + 0.2 = 0.30000000000000004) — unacceptable for money.

Consolidation

ASC 810/830 — combining multi-entity groups: IC eliminations, minority interest, FX translation, cumulative translation adjustment.

Period close

Locking an accounting period; soft close permits adjusting entries (policy decision GAP-4), hard close locks posting.

RBAC

Role-based access control — permissions enforced on the server and in data filtering.

Tauri

Rust-based desktop application framework; produces a small native installer with local data.

EPM

Enterprise Performance Management — the incumbent software category FinPlan Pro competes with.

NCI / minority interest

The portion of a subsidiary not owned by the parent — computed exactly in consolidation.

GAP-7

CI hardening program (SHA-pinning of GitHub Actions + bundle cap) currently blocked on the workflows permission.
