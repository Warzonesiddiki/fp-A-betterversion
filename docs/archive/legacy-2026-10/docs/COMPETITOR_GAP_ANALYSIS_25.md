## Critical Missing Features (TIER 1 — Must Build)

### 1. Natural Language Queries (NLQ)

**Competitors:** Vena Copilot, Cube AI, Oracle GenAI, SAP SAC, Mosaic Arc AI
**What:** Type "show Q3 revenue by region" → auto-generates chart/table
**FinPlan Status:** AIEngine exists, @huggingface/transformers installed, but NLQ not built
**Build:** Wire AIEngine to formula parser + chart generator. 4 hours.
**Impact:** 1000x — first offline NLQ in FP&A

### 2. Real-Time Collaboration

**Competitors:** ALL 25 have this
**What:** Multiple users edit same budget simultaneously (Google Docs-style)
**FinPlan Status:** Comments + tasks exist, but no real-time sync
**Build:** CRDT-based sync or WebSocket. 8+ hours. BUT: offline-first = no backend
**Impact:** HIGH but conflicts with offline-first architecture
**Decision needed:** Skip (offline-first moat) or add optional cloud sync

### 3. ERP Connectors

**Competitors:** ALL 25 have this
**What:** Pre-built connectors to QuickBooks, NetSuite, Salesforce, SAP, etc.
**FinPlan Status:** Excel/CSV import only
**Build:** REST API connector framework + QuickBooks/NetSuite adapters. 16+ hours.
**Impact:** HIGH — enterprise requirement
**Decision needed:** Build connector framework or stay Excel-focused

### 4. 3-Statement Financial Model

**Competitors:** 20/25 have this
**What:** Integrated P&L + Balance Sheet + Cash Flow with automatic linking
**FinPlan Status:** Individual statements exist, but no integrated model
**Build:** Wire existing engines together. 4 hours.
**Impact:** HIGH — core FP&A requirement

### 5. Template Library

**Competitors:** 22/25 have this
**What:** Pre-built templates for budgets, forecasts, reports by industry
**FinPlan Status:** No templates
**Build:** Create 20+ templates across sectors. 8 hours.
**Impact:** MEDIUM — speeds up onboarding

### 6. Zero-Based Budgeting

**Competitors:** Anaplan, OneStream, Oracle EPM
**What:** Build budget from zero each period, not incremental
**FinPlan Status:** Not built
**Build:** Add ZBB mode to budget engine. 4 hours.
**Impact:** MEDIUM — differentiator for cost-conscious orgs

### 7. Tax Reporting

**Competitors:** OneStream, Oracle EPM
**What:** Tax provision, transfer pricing, tax compliance
**FinPlan Status:** TransferPricingEngine exists (171 lines), TaxProvisionEngine exists (153 lines)
**Build:** Wire to UI pages. 2 hours.
**Impact:** MEDIUM — compliance requirement
