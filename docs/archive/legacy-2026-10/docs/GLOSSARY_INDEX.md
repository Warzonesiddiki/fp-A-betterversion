# FinPlan Pro — FP&A Glossary Index

> One-line summary per term, alphabetical. Full definitions in `docs/GLOSSARY.md`.

| Term                                                                                  | One-line summary                                                                           |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| [ARR](GLOSSARY.md#arr-annual-recurring-revenue)                                       | Annualised value of active subscriptions (run-rate for SaaS).                              |
| [Balance Sheet](GLOSSARY.md#balance-sheet)                                            | Point-in-time statement: Assets = Liabilities + Equity.                                    |
| [Budget vs Actual](GLOSSARY.md#budget-vs-actual)                                      | Variance report comparing planned vs realised amounts.                                     |
| [Burn Rate](GLOSSARY.md#burn-rate)                                                    | Monthly (or annual) cash spend; drives Runway.                                             |
| [CAC](GLOSSARY.md#cac-customer-acquisition-cost)                                      | Sales+Marketing spend ÷ new customers in a period.                                         |
| [Cash Flow](GLOSSARY.md#cash-flow)                                                    | Operating / Investing / Financing cash movements for a period.                             |
| [Churn](GLOSSARY.md#churn)                                                            | % of customers (or revenue) lost per period.                                               |
| [COGS](GLOSSARY.md#cogs-cost-of-goods-sold)                                           | Direct cost of producing goods/services sold in a period.                                  |
| [DCF](GLOSSARY.md#dcf-discounted-cash-flow)                                           | Present value of projected free cash flows, discounted at WACC.                            |
| [EBITDA](GLOSSARY.md#ebitda-earnings-before-interest-taxes-depreciation-amortization) | Net income with interest, tax, D&A added back; operating-profit proxy.                     |
| [FP&A](GLOSSARY.md#fpa-financial-planning--analysis)                                  | The corporate function that owns budgeting, forecasting, and analysis.                     |
| [Forecast](GLOSSARY.md#forecast)                                                      | Forward estimate of revenue/expense/cash; can be driver-based, statistical, or judgmental. |
| [IRR](GLOSSARY.md#irr-internal-rate-of-return)                                        | Discount rate at which NPV of cash flows = zero.                                           |
| [LTV](GLOSSARY.md#ltv-lifetime-value)                                                 | Total gross-margin revenue a customer generates over their lifetime.                       |
| [Monte Carlo](GLOSSARY.md#monte-carlo)                                                | Repeated simulation sampling uncertain inputs to estimate an output distribution.          |
| [MRR](GLOSSARY.md#mrr-monthly-recurring-revenue)                                      | Normalised monthly value of active subscriptions.                                          |
| [NPV](GLOSSARY.md#npv-net-present-value)                                              | Sum of future cash flows discounted to the present.                                        |
| [NRR](GLOSSARY.md#nrr-net-revenue-retention)                                          | Recurring revenue retained from existing customers, including expansion.                   |
| [OLAP](GLOSSARY.md#olap-online-analytical-processing)                                 | Multi-dimensional cube for fast slice/dice/drill-down on large data.                       |
| [P&L](GLOSSARY.md#pl-profit--loss)                                                    | Income statement: Revenue → COGS → GP → OpEx → EBITDA → Net Income.                        |
| [Runway](GLOSSARY.md#runway)                                                          | Months of operation remaining at current burn before cash hits zero.                       |
| [Scenario](GLOSSARY.md#scenario)                                                      | Named "what-if" view with consistent driver overrides.                                     |
| [Sensitivity Analysis](GLOSSARY.md#sensitivity-analysis)                              | One-at-a-time flex of inputs to measure output impact (tornado / data table).              |
| [Variance](GLOSSARY.md#variance)                                                      | Actual vs budget/forecast/prior; decomposed into price/volume/mix.                         |
| [Working Capital](GLOSSARY.md#working-capital)                                        | Current Assets − Current Liabilities; short-term liquidity.                                |
