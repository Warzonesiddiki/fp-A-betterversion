MissionThe one-stop FP&A platform for every industry

Finance teams today stitch together 4–6 tools for budgeting, forecasting, consolidation, close and reporting. FinPlan Pro replaces the stack with one offline-first desktop suite — fast, private, audit-grade.

All-industry depth

Sector configs & templates across manufacturing, banking, retail, SaaS, healthcare, energy, government, construction, real-estate, telecom, logistics, education — expansion queue is costed, not guessed.

Audit-grade math

Every covered currency path routes through one exact-decimal primitive (money.ts: ROUND_HALF_UP, divide-by-zero throws) — enforced by a README claim gate that fails the build if docs drift from code.

Local-first trust

Data stays on-device by default. Optional self-hosted backend (Express + SQLite, RBAC, JWT rotation) — never a cloud requirement.

Decisions I need todayFive rulings unlock the last mile

1 · Encryption-key recovery UX

Today a device wipe destroys encrypted history (key lives beside data).

Recommended: optional passphrase escrow, opt-in at onboarding; default unchanged for offline-first purists.

2 · Plugin marketplace posture

Sandbox is now real; install-path integrity checks are still stubbed.

Recommended: keep marketplace disabled until signed-manifest evidence exists (path-lock compliant).

3 · Server integration scope

SDK now targets env-configured origin only; auth client unwritten.

Recommended: green-light auth client (mock fallback preserved) — unlocks multi-user story.

4 · Browser vs PWA story

App hard-blocks browsers while shipping an installable PWA manifest.

Recommended: desktop-only positioning stands; retire the PWA surface until a web tier is a funded decision.

5 · Desktop updater channel

No updater configured while lib.rs claimed one — false claim already flagged; a finance desktop app needs a patch channel before beta.

Recommended: self-hosted updater (static JSON + signed artifacts on existing infra) — cheapest secure option, no vendor lock.
