## Executive Summary

The FP&A market is segmented into three tiers:

| Tier            | Competitors                                                              | Price Range         | Target           |
| --------------- | ------------------------------------------------------------------------ | ------------------- | ---------------- |
| **SMB/Starter** | Cube, Aleph, Syft, XPNA, Stratify                                        | $500-$2,000/mo      | 1-50 employees   |
| **Mid-Market**  | Drivetrain, Abacum, Farseer, Una, Datarails, Runway, Pigment             | $1,000-$5,000/mo    | 50-500 employees |
| **Enterprise**  | Anaplan, Board, Jedox, Prophix, Vena, Planful, insightsoftware, NetSuite | $5,000-$100,000+/yr | 500+ employees   |

**Key market trends:**

- AI-native platforms are displacing legacy tools (Abacum, Pigment, Runway leading)
- Excel-native remains critical (Vena, Datarails, Cube dominate this niche)
- Consolidation is table-stakes for mid-market+
- Scenario planning is the #1 requested differentiator
- API ecosystems are expanding rapidly (700+ integrations becoming standard)
