## PART 2 — NUMERIC LAW (single normative chapter; supersedes v4 Part V fragments)

- **Pipeline (canonical):** string|number input → Decimal compute through any aggregation chain → tagged-string persistence at masterStorage boundary → formatting only at display edge. JSON.stringify round-trips IEEE-754 — therefore **money persists as strings** (closes the serialization hole).
- **Rounding:** ROUND_HALF_UP default per ADR-012 (evidenced 0.005 proof); HALF_EVEN only mandated at statutory call sites. v4's silent HALF_EVEN reversal is REJECTED (or re-adjudicated formally with proof on table).
- **Three-statement runtime gate, three layers (works offline):**
  1. pure `verifyThreeStatements()` engine fn (unit-tested, no IO);
  2. persistence-boundary hook in masterStorage/persist middleware — snapshots violating TS1–TS3 never COMMIT (save/import/publish/period-lock/post-worker-recalc; never per-keystroke);
  3. server-side gate at publication/approval endpoints once Plane B wired.
- **Quarantine semantics:** unbalanced drafts stay visible read-only with TS5 structured error (identity + delta + offending cells). "Cannot be disabled" applies to COMMITS only — never hold an offline user hostage to their own books.
- **Conservation:** TS1–TS3 + N11/N18 property-based oracles; post-elimination intercompany nets are EXACTLY zero (N19 has no tolerance fudge — recon items go through explicit accounts).
- **Migration honesty:** current state = decimal.js in a minority of engine modules (site/module counts to be stamped §8); CI triple-gate = AST detector on NEW violations + oracles + persistence round-trip byte-exact test; declared deviation register, ratchet toward zero.
- Precedence: this Part > BLUEPRINT §6 > AGENTS.md conventions; AGENTS.md "raw number" text amends at ADR-004 ratification.
