## §6. Root Cause

The 6 failed specs were created by the Edit tool modifying the v0.1 file in place (rather than appending §0a addendum), then copy-renaming the unchanged file to v0.1.1. The "bump" was purely a filename change with NO content modification.

**Why D-019 5-witness caught it but D-002 3-witness did not**:

- D-002 W3 reads SHA256 from frontmatter (TRUSTED)
- D-019 W3 computes SHA256 EXTERNALLY via Get-FileHash (UNTRUSTED verification)
- When v0.1 and v0.1.1 are byte-identical, W3 EXTERNAL returns matching hashes for both — discrepancy with frontmatter would also be a catch, but here the frontmatter SHA256 was copied from v0.1, so it MATCHES the external hash for v0.1.1, masking the fabrication under D-002.
