## §1 3 Sub-Classes MECE Taxonomy

**Definition (cat 4 sub-class 1 sub-class e)**: A CATCH that is "amplified" or "narratively inflated" by the catching Muse's own prior catches or by the cite-bundle used as evidence. 3 MECE sub-classes:

### §1.1 Sub-class e.i — Cite-Bundle Fabrication

**Definition**: The catching Muse's cite-bundle (raw line counts, byte counts, or external references) is INFLATED, FABRICATED, or NOT 3-witness verified at SHIP time. The cite-bundle claims file/line facts that are WRONG or unverifiable.

**Trigger conditions**:

- Cite-bundle line counts (e.g., "514L") stated without W4 filesystem-stat verification (wc -l + Get-ChildItem Length)
- Cite-bundle byte counts (e.g., "10063B") stated without W4 verification
- External references (URLs, file paths) cited without Read/Glob ABSOLUTE verification

**Mitigation**: Every numeric claim in cite-bundle MUST be W4 filesystem-stat verified at SHIP time, NOT at PICK time. Codif 9 v0.2 W4 ritual codified (see §3).

### §1.2 Sub-class e.ii — R-Catch Amplification

**Definition**: A CATCH is triggered FROM another CATCH (i.e., the catching Muse's response catches Hephaestus/other Muse's action on a prior CATCH, which itself was questionable). The new CATCH is "amplified" by the prior CATCH's uncertainty.

**Trigger conditions**:

- CATCH Y is triggered in response to actions on a CATCH X where CATCH X is itself CATCH-43-DISPUTED, IN-PROGRESS, or PENDING
- The Muse catching Y may have propagated the CATCH X narrative without re-verification (Codif 9 v0.2 §3 5-state model)

**Mitigation**: When catching a CATCH X that is itself uncertain, the new CATCH Y must re-verify CATCH X's underlying facts (e.g., CATCH #44 R-catch amp on T-HEP-029 v0.1 required re-verification of T-HEP-029 v0.1's actual file existence via 3-witness Codif 9 v0.2).

### §1.3 Sub-class e.iii — Fabrication-of-Numbers

**Definition**: Specific numeric claims in a cite-bundle (file size in bytes, line count, SHA256 hash, version number) are WRONG — i.e., the cited number does not match the actual file on disk.

**Trigger conditions**:

- Cited line count ≠ wc -l output
- Cited byte count ≠ Get-ChildItem Length
- Cited SHA256 hash ≠ actual file SHA256
- Cited version number (e.g., v0.1) ≠ actual filename version

**Mitigation**: All numeric claims MUST be W4 filesystem-stat verified at SHIP time. Per CATCH #44 SELF-CATCH (Hephaestus), T-HEP-030 v0.1 SHIP-COMPLETE CORRECTED cite-bundle is 320L (was 514L INFLATED). The correction itself is a Codif 7 v0.2 self-correction arc exemplar. **CATCH #46 SELF-CATCH (Iris, this turn) extends the pattern to T-IR-037 v0.1 itself** — see §10.5.
