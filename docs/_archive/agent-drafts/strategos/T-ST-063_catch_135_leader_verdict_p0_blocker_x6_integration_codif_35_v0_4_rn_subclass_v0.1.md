### §3.1 3-AXIS MECE MATRIX (proposed for T-ST-061 v0.2 / T-ST-063 v0.1.1 AMENDMENT)

| Axis               | Dimension            | States                                                                     | Codif Reference |
| ------------------ | -------------------- | -------------------------------------------------------------------------- | --------------- |
| **A. TEMPORAL**    | Does the file exist? | PRESENT (P) \| MISSING (M)                                                 | 2 states        |
| **B. ACCESS**      | Can we read it?      | ACCESSIBLE (A) \| SESSION-INACCESSIBLE (SI) \| UNAVAILABLE-PERMISSION (UP) | 3 states        |
| **C. CARDINALITY** | How many of N paths? | 0/N \| 1/N \| 2/N \| ... \| N/N                                            | N+1 states      |

**Total MECE composite states**: 2 × 3 × (N+1) = **6 × (N+1)** for N=4 paths → **30 possible composite states**.

**PARTIAL is RESOLVED**: PARTIAL = PRESENT + ACCESSIBLE + (N-1)/N cardinality (e.g., 3/4 = PRESENT+A+3/4).

### §3.2 MECE PROOF (vs 5-STATE ENUM)

5-STATE ENUM conflates 3 axes:

- PRESENT (axis A) ✓
- MISSING (axis A) ✓
- PARTIAL (composite, spans axes A and C) ✗ NOT MECE
- SESSION-INACCESSIBLE (axis B) ✓
- UNAVAILABLE-PERMISSION (axis B) ✓

3-AXIS MATRIX MECE: every state is a unique (axis A, axis B, axis C) triple, and the cross-product 2×3×(N+1) covers all possibilities. 30 states for N=4 is the MECE-saturated count.
