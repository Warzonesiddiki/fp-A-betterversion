# Release Process

## Overview

Releases follow a rigorous zero-compromise audit and gating checklist.

## Steps

1. **Verification Battery**: TypeScript compilation, ESLint (`--max-warnings 0`), README claim checks, dependency audits, and security test suites.
2. **Review & Sign-Off**: Multi-muse audit verdict verification (`ZCFA-2026-07-28-001` closure tracking).
3. **Tagging & Artifacts**: Signed git tags and secure artifact builds.
