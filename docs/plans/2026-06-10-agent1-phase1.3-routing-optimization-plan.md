# Phase 1.3 — Routing & Lazy Loading Optimization

## Objective
Audit and optimize React Router lazy loading. Ensure all route pages are code-split, preload critical routes, and eliminate waterfalls.

## Current State
- `src/App.tsx` uses `React.lazy(() => import('./pages/...'))` for all routes
- Lazy imports split into chunks automatically by Vite
- `ErrorBoundary` and `AsyncErrorBoundary` wrapping applied
- No route-level preloading strategy visible

## Code Pattern

```tsx
const Dashboard = lazy(() => import('@/pages/dashboard/DashboardPage'));

// Preload critical routes on hover/idle
const preloadDashboard = () => import('@/pages/dashboard/DashboardPage');

// In nav component:
<Link to="/dashboard" onMouseEnter={preloadDashboard} />
```

## Acceptance Criteria
- All routes preserve lazy loading (no regression to eager imports)
- Critical routes (Dashboard, Budget, Reports) have hover/intent preloading
- No render waterfalls from nested lazy imports
- Route chunk names match `pages-[routeName]` pattern
