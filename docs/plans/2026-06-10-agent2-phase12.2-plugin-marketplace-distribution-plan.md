# Phase 12.2 — Plugin Marketplace & Distribution

**Objective**: Plugin discovery, marketplace, and distribution system.

## Dependencies
- Phase 12.1 plugin registry and sandbox
- Existing `src/plugins/` directory

## Implementation Tasks

### 1. Plugin Marketplace UI (src/components/plugins/PluginMarketplace.tsx)
- Plugin catalog with categories
- Search and filter plugins
- Plugin detail page (screenshots, description, rating, version)
- One-click install from marketplace
- Update notifications for installed plugins

### 2. Plugin Packaging
- Plugin package format (.finplan-plugin, ZIP)
- Package signature verification
- Manifest validation on install
- Dependency bundling
- Size limits and resource budgets

### 3. Plugin Developer Portal
- Developer registration
- API key management
- Submission workflow (upload, review, publish)
- Version management (semantic versioning)
- Analytics for plugin authors

### 4. Plugin Settings UI (src/components/plugins/PluginSettingsPanel.tsx)
- Per-plugin settings page
- Configuration schema (JSON Schema rendered as form)
- Permission management
- Resource usage display
- Enable/disable toggle
- Uninstall with confirmation

## Verification
- Marketplace loads and displays plugins
- Install from marketplace succeeds
- Plugin settings page renders configuration form
- Permissions display and grant correctly
- Update flow works end-to-end
