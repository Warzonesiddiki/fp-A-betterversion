# Phase 11.2 — Approval Workflow Engine

**Objective**: Multi-stage approval workflows with routing rules, notifications, and audit trail.

## Dependencies

- Existing components: `src/components/approval/`
- Existing `WorkflowEngine`, `WorkflowActionEngine`, `VisualWorkflowEngine`, `StateMachine`

## Implementation Tasks

### 1. Approval Store (src/store/approvalStore.ts)

- Zustand with Immer + subscribeWithSelector
- State: workflows, approvals, rules, templates, audit
- Actions: createWorkflow, submitForApproval, approve, reject, recall
- Persist via masterStorage
- Optimistic updates for immediate UI feedback

### 2. Approval Workflow Designer (src/components/approval/ApprovalWorkflowDesigner.tsx)

- Visual workflow editor (drag-and-drop nodes)
- Step types: submit, review, approve, reject, counter-sign, conditional routing
- Approval chain configuration (sequential, parallel, any-of)
- Dynamic routing rules (amount-based, org-based)
- Escalation rules with timeouts

### 3. Approval Request UI (src/components/approval/ApprovalRequest.tsx)

- Submit for approval dialog
- Select workflow template
- Add comments and attachments
- Select reviewers
- Preview approval chain
- Submit with confirmation

### 4. Approval Inbox (src/components/approval/ApprovalInbox.tsx)

- Pending approvals grouped by priority
- Approve/reject with optional comment
- Delegate approval to another user
- View full model/budget context inline
- Approval history for each request

### 5. Approval Templates

- Named approval templates (capital expenditure, budget, forecast)
- Configurable by type/amount/org
- Template versioning
- Template inheritance (override specific steps)
- Template library with categories

### 6. Audit & Reporting

- Complete approval audit trail
- Approval cycle time metrics
- Bottleneck detection
- Approval compliance reports
- Export for SOX/compliance

## Verification

- Workflow designer creates valid workflows
- Approval routes through correct chain
- Rejection sends back with proper notification
- Audit trail captures all events
- Templates apply with correct defaults
