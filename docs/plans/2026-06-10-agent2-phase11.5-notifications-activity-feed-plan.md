# Phase 11.5 — Notifications & Activity Feed

**Objective**: Unified notification system with real-time alerts, digest, and preferences.

## Dependencies
- Phases 11.1-11.4
- Existing engines

## Implementation Tasks

### 1. Notification Service (src/services/NotificationService.ts)
- Push notifications via WebSocket
- Email digest (daily/weekly)
- In-app notification center
- Notification templates per type
- Deduplication of similar notifications

### 2. Notification Center UI (src/components/approval/NotificationCenter.tsx)
- Bell icon with unread count badge
- Dropdown list with recent notifications
- Filter by type (approval, comment, alert, system)
- Mark read/unread
- Clear all
- Click to navigate to context

### 3. Notification Preferences
- Per-user notification preferences
- Channel preferences (in-app, email, push)
- Quiet hours configuration
- Per-event-type toggle
- Digest schedule (realtime, hourly, daily)

### 4. Activity Feed (src/components/approval/ActivityFeed.tsx)
- Chronological activity log per entity
- Activity types: edit, comment, approve, reject, submit, lock, unlock
- User avatars with timestamps
- Filter and search activities
- Activity detail expansion

### 5. Email Notifications
- Email templates per notification type
- HTML email with action buttons
- Plain text fallback
- Unsubscribe link
- Email delivery status tracking

## Verification
- Notifications appear in real-time
- Email digest delivers on schedule
- Preferences persist and take effect immediately
- Activity feed shows accurate history
- Click notification navigates to correct context
