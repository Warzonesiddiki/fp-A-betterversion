# Phase 4.5 — Close Management

## Objective
Build close management dashboard — close checklist, task assignments, status tracking, close calendar.

## Current State
- No close management UI exists
- Consolidation engines process data but no workflow
- WorkflowEngine can be extended

## Work Units
| # | Task | Effort |
|---|------|--------|
| 1 | Design close task template (recurring monthly/quarterly tasks) | 2h |
| 2 | Build close calendar with task dependencies | 3h |
| 3 | Build close dashboard (task status, blockers, SLA) | 4h |
| 4 | Add task assignment and notifications | 2h |
| 5 | Add sign-off workflow (prepare → review → approve → close) | 3h |
| 6 | Add close analytics (days to close, bottleneck identification) | 2h |

## Acceptance Criteria
- Close calendar shows all tasks with dependencies
- Status dashboard shows % complete per entity
- Sign-off requires reviewer + approver
- Days-to-close trend tracked month over month
- Task SLA breach triggers alert
