# Phase 9.2 — Data Quality & Validation Engine

**Objective**: Comprehensive data quality validation rules, duplicate detection, and integrity checks.

## Dependencies
- Phase 9.1 stores and services
- Existing `ValidationEngine`, `DataQualityEngine`, `DataClassificationEngine`

## Implementation Tasks

### 1. GL Validation Engine (src/engines/GLValidationEngine.ts)
- Row-level validation (missing fields, wrong types, out of range)
- Cross-row validation (duplicate detection, sequential checks)
- Balance check (debits = credits per batch)
- Account code validation against chart of accounts
- Date range validation (fiscal period boundaries)

### 2. Data Quality Dashboard (src/components/data/DataQualityPanel.tsx)
- Error summary with severity counts
- Drill-down to individual row errors
- Fix suggestions for common errors
- Export error report to CSV

### 3. Duplicate Detection Service (src/services/DuplicateDetectionService.ts)
- Configurable match keys (account + date + amount + reference)
- Fuzzy matching for descriptions
- Tolerance for amount differences
- Batch duplicate scan with progress

### 4. Integrity Check Engine (src/engines/IntegrityCheckEngine.ts)
- Referential integrity (accounts exist in chart)
- Period continuity (no gaps)
- Currency consistency
- Entity/department cross-reference

## Verification
- All validation tests pass
- Duplicate detection catches known duplicates
- Dashboard renders error counts correctly
