# Phase 17.2 — Render Performance Plan

**Agent:** A5 | **Phase:** 17 Performance & Offline | **Subphase:** 2/5
**Created:** 2026-06-10 | **Status:** pending

## Objective
Improve rendering performance via React profiler analysis, AG Grid row model optimization, virtualization audit, and memoization review.

## Current State
- AG Grid with community edition (35.x)
- React 19 with automatic batching
- Zustand stores with `subscribeWithSelector`
- Unknown memoization coverage
- No React Profiler baseline recorded

## Execution Steps

### Step 1: React Profiler Baseline
- [ ] Add `<Profiler>` to App.tsx for key routes
- [ ] Profile DashboardPage, BudgetGrid, ReportGrid
- [ ] Measure mount time, commit count, render duration
- [ ] Record baseline metrics in perfBudgets.ts

### Step 2: AG Grid Row Model Audit
- [ ] Verify all grids use `rowModelType: 'clientSide'` or `'serverSide'` correctly
- [ ] Audit column definitions for unnecessary re-renders
- [ ] Check `getRowId` usage for stable row identity
- [ ] Review cell renderer memoization
- [ ] Enable `suppressColumnVirtualisation` only when needed

### Step 3: Memo Audit
- [ ] Audit `React.memo` usage on large components
- [ ] Check `useMemo`/`useCallback` on expensive computations
- [ ] Audit Zustand selector stability (primitive selectors)
- [ ] Review context providers for unnecessary re-renders

### Step 4: Virtualization Audit
- [ ] Review @tanstack/react-virtual usage
- [ ] Check list virtualization in large dropdowns/selects
- [ ] Verify windowing in report/book builders

### Step 5: Animation Performance
- [ ] Review framer-motion usage for layout thrashing
- [ ] Audit `will-change` and `transform` usage
- [ ] Check for forced reflow patterns

## Success Criteria
- [ ] Mount time < 100ms for all pages
- [ ] AG Grid render < 50ms for 1000 rows
- [ ] No unnecessary re-renders in store subscribers
- [ ] 60fps animations
