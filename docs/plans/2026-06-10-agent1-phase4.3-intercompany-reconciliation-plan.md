# Phase 4.3 — Intercompany Reconciliation

## Objective
Build IC reconciliation workflow — matching engine, dispute management, aging dashboard.

## Current State
- Basic IC elimination exists in ConsolidationEngine
- No dedicated reconciliation workflow or UI

## Work Units
| # | Task | Effort |
|---|------|--------|
| 1 | Build IC matching rules (exact, tolerance, fuzzy by description) | 3h |
| 2 | Build IC reconciliation dashboard (aged IC items, unmatched, disputed) | 4h |

| 4 | Add IC confirmation matching (send/receive confirmations) | 2h |
| 5 | Add IC aging report (30/60/90/120+ days) | 2h |
| 6 | Write reconciliation engine tests | 2h |

## Acceptance Criteria
- Matching auto-pairs > 90% of IC items by amount + counterparty
- Aging dashboard shows unmatched items by entity and age
- Dispute workflow includes comments and evidence attachments
- Confirmation process matches counterparty entries
