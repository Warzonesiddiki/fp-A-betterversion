# Phase 1.1 — Build System Auditing

## Objective

Audit Vite build config, measure bundle size, chunk composition, and tree-shaking efficacy. Establish baseline metrics and produce remediation plan.

## Baseline Metrics (Captured 2026-06-10)

| Metric               | Value                                                                         |
| -------------------- | ----------------------------------------------------------------------------- |
| TSC errors           | 329                                                                           |
| Build status         | ✅ Succeeds                                                                   |
| Largest chunk        | `ort-wasm-simd-threaded.asyncify.wasm` — 23,567 KB (gzip 5,824 KB)            |
| CSS chunk            | `index.css` — 163 KB (gzip 25 KB)                                             |
| ManualChunks         | react-vendor, chart-vendor, grid-vendor, form-vendor, state-vendor, ai-vendor |
| Plugins              | @tailwindcss/vite, VitePWA, rollup-plugin-visualizer, react-router            |

## Findings

### 1. WASM Overhead

- `ort-wasm-simd-threaded.asyncify.wasm` at 23 MB (raw) / 5.8 MB (gzip) dominates bundle
- Likely from ONNX Runtime (NLQEngine, AIEngine). Consider:
  - Lazy-load ONNX runtime only when AI features used
  - Use `ort-wasm-simd` (non-asyncify) if threading not required
  - Move to Web Worker with dynamic import

### 2. CSS Bundle Size

- `index.css` at 163 KB raw / 25 KB gzip is high for initial load
- Tailwind generates all utility classes. Check `content` paths coverage.
- Consider: purging unused classes (may already happen — verify)

### 3. Chunk Structure

- Manual chunk groups could be optimized:
  - `chart-vendor`: Consider splitting Recharts + custom chart components
  - `state-vendor`: Consider separating Zustand + Immer + persist middleware from TanStack Query
  - `ai-vendor`: Already separate — verify ONNX/NLQ is here

### 4. TypeScript Strictness Gap

- 329 TSC errors. Categorized:
  - `noUncheckedIndexedAccess` violations (~40%) — array/object access without bounds check
  - Type mismatches in test files (~25%) — mock types not aligned
  - Missing properties on union types (~15%)
  - Other (~20%) — unused params, implicit any, etc.

## Recommended Actions

| Priority | Action                                                       | Expected Impact                |
| -------- | ------------------------------------------------------------ | ------------------------------ |
| P0       | Lazy-load WASM (ONNX) module                                 | -5.8 MB gzip from initial load |
| P1       | Audit CSS content paths in tailwind config                   | -30-50% CSS size               |
| P2       | Add bundle size CI gate (150KB main, 2MB total)              | Prevents regression            |
| P2       | Enable `noUnusedLocals` + `noUnusedParameters` incrementally | Dead code removal              |
| P3       | Split grid-vendor into ag-grid-react + ag-grid-community     | Faster grid loads              |
| P3       | Add Vite bundle visualizer report to CI artifacts            | Ongoing visibility             |

## Execution Commands

```bash
# Regenerate baseline
npx tsc --noEmit 2>&1 | Measure-Object -Line > tsc-errors-count.txt
node node_modules/vite/bin/vite.js build --emptyOutDir > build-output.txt

# Bundle analysis
npx vite-bundle-analyzer  # if installed
```
