# Phase 10.5 — What-If Analysis & Goal Seek

**Objective**: Interactive scenario modeling with goal seek, sensitivity tables, and data tables.

## Dependencies

- Existing `GoalSeekEngine`, `SensitivityEngine`, `SolverEngine`, `WhatIfSandboxEngine`, `ScenarioEngine`
- Phase 10.1 grid

## Implementation Tasks

### 1. Goal Seek Dialog (src/components/spreadsheet/GoalSeekDialog.tsx)

- Set cell / to value / by changing cell
- Multi-variable goal seek
- Convergence settings (max iterations, tolerance)
- Progress display during solve
- Result preview with confidence indicator

### 2. Sensitivity / Data Table Builder (src/components/spreadsheet/DataTableBuilder.tsx)

- Row input cell and column input cell
- One-variable and two-variable data tables
- Auto-fill results grid
- Result visualization (heat map, line chart)
- Scenario comparison table

### 3. Scenario Manager (src/components/spreadsheet/ScenarioManager.tsx)

- Named scenarios with changed cells
- Scenario summary report
- Scenario merging and comparison
- Scenario pivot table (what-if on multiple outputs)
- Save/load scenarios

### 4. Solver Configuration (src/components/spreadsheet/SolverDialog.tsx)

- Objective cell (min/max/value)
- Variable cells with bounds
- Constraints builder (≤, =, ≥, integer, binary)
- Solve method selection (GRG, simplex, evolutionary)
- Solver results and sensitivity report

### 5. Audit Trail for What-If

- Record all what-if operations
- Undo/redo per scenario change
- Snapshot comparison
- Export audit log

## Verification

- Goal seek converges to correct value
- Data tables populate all cells correctly
- Scenarios apply and switch without data loss
- Solver finds optimal within constraints
- Audit trail records all changes
