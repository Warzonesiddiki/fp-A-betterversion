# Phase 12.3 — Security Hardening & RBAC

**Objective**: Comprehensive security: RBAC, audit logging, encryption, and data protection.

## Dependencies

- Existing `RBACEngine`, `EncryptionEngine`, `DataMaskingEngine`, `AuditLogEngine`
- Existing `SecurityEngine`, `CellProtectionEngine`

## Implementation Tasks

### 1. RBAC Enhancement (src/services/RBACService.ts)

- Role hierarchy with inheritance
- Permission matrix (entity × action × scope)
- Dynamic role assignment rules
- Temporary role elevation with justification
- Role simulation/preview for admins

### 2. Audit Log Service Enhancement

- Structured audit events (who, what, when, where, context)
- Immutable audit log (append-only, signed)
- Audit query builder with filters
- Audit export for compliance
- Alert on suspicious audit patterns

### 3. Encryption Service

- Data at rest encryption (IndexedDB level)
- Field-level encryption for PII/sensitive fields
- Key management with key rotation
- Encrypted export/import
- Client-side encryption before sync

### 4. Data Masking Engine Enhancement

- Dynamic masking based on user role
- Masking patterns (credit card, SSN, account numbers)
- Show full on hover with permission check
- Masking audit trail
- Configurable masking rules per field

### 5. Security Dashboard

- Active sessions per user
- Failed login attempts
- Permission change log
- Security health score
- Compliance status (SOX, GDPR, SOC2)

## Verification

- RBAC correctly restricts access
- Audit log captures all events immutably
- Encrypted data is unreadable without key
- Masking hides sensitive data by role
- Security dashboard shows accurate state
