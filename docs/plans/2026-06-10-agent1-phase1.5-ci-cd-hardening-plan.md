# Phase 1.5 — Build, CI/CD & Configuration Hardening

## Objective
Harden Vite config, add CI gating for bundle size, optimize PWA manifest, and verify Tauri integration.

## Current State
- CI order (per AGENTS.md): `tsc --noEmit → lint → test → build → bundle size check`
- Main chunk target: < 150KB gzip, total JS < 2MB gzip
- PWA via vite-plugin-pwa with workbox autoUpdate
- Tauri desktop: `npm run tauri:dev` / `npm run tauri:build`
- CI: Node 22, `npm ci`

## CI Gate Script

```ts
// scripts/check-bundle-size.ts
const limits = {
  'assets/index-*.js': 150_000,       // 150KB gzip main JS
  'assets/index.css': 25_000,          // 25KB gzip CSS
  'assets/*.wasm': 6_000_000,         // 6MB gzip total WASM
};
```

## Acceptance Criteria
- CI fails if main chunk > 150KB gzip
- CI fails if total non-WASM JS > 2MB gzip
- Tauri allowlist reviewed and documented
- Code signing certs obtained and configured
- Bundle visualizer accessible in CI artifacts
