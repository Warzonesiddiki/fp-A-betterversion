# Phase 11.1 — Real-Time Collaboration

**Objective**: Multi-user real-time collaboration on budgets, models, and reports.

## Dependencies

- Existing services: `PresenceService`, `RealtimeCollaborationManager`, `WebSocketManager`, `ChangeBroadcaster`
- Existing components: `src/components/collaboration/`

## Implementation Tasks

### 1. Presence & Awareness UI (src/components/collaboration/PresenceBar.tsx)

- Active user avatars with status (editing, viewing, idle)
- Cursor position indicators on grid
- Current cell selection per user
- Session join/leave notifications
- User color assignment (consistent per session)

### 2. Operational Transform Engine (src/engines/OperationalTransformEngine.ts)

- OT for simultaneous edits on same cell
- Merge strategies (last-write-wins, merge, manual)
- Conflict detection with visual indicators
- Auto-resolve common conflicts
- Undo-aware OT (undo one user's changes)

### 3. Change Broadcasting Service Enhancement

- WebSocket message protocol (JSON-RPC over WS)
- Message batching for high-frequency changes
- Compression for large payloads
- Reconnection with state sync
- Offline queue with replay on reconnect

### 4. Collaboration Comments

- Threaded comments on cells/ranges
- @mention users with notification
- Resolve/reopen comments
- Comment history with edit trail
- Comment export for audit

### 5. Session Management

- Create/manage collaboration sessions
- Invite users (link, email, direct)
- Session permissions (viewer, editor, owner)
- Session history and activity log
- Auto-cleanup idle sessions

## Verification

- Two users can edit same sheet simultaneously
- Cursor positions visible to all users
- Conflicts detected and resolved
- Comments persist and notify @mentioned
- WebSocket reconnects after disconnect
