# Phase 9.1 — GL Data Import Engine

**Objective**: Build trial balance / GL data import pipeline with validation, mapping, and preview.

## Dependencies
- Existing: `ImportEngine`, `ExcelImportEngine`, `SmartImportMapper`, `StreamImportEngine`
- Existing components: `GLDropZone`, `GLColumnMapper`, `GLDataPreview`, `GLTrialBalanceGrid` (all with tests, all passing)

## Implementation Tasks

### 1. Store — GL Upload Store (src/store/glUploadStore.ts)
- Zustand store with Immer + subscribeWithSelector
- State: status, file, preview data, mappings, errors, progress
- Actions: setFile, setMappings, setPreview, clearUpload, confirmImport
- Persist via masterStorage

### 2. Store — GL Trial Balance Store (src/store/glTrialBalanceStore.ts)
- Zustand store for trial balance data display
- State: accounts, periods, balances, filters, loading, error
- Actions: loadData, filterByAccount, filterByPeriod, sortByColumn

### 3. Service — GL Import Service (src/services/GLImportService.ts)
- Wraps ImportEngine + ExcelImportEngine
- CSV auto-detection (delimiter, encoding)
- Excel (.xlsx) parsing via existing ExcelImportEngine
- Column mapping persistence (learned mappings)
- Validation pipeline (date, numeric, required fields)
- Preview data generation
- Bulk import streaming via StreamImportEngine

### 4. Pipeline Integration — ImportPipeline (src/services/ImportPipeline.ts)
- Orchestrates: detect → parse → map → validate → preview → import
- Progress reporting per stage
- Error aggregation with row-level detail
- Snapshot for rollback
