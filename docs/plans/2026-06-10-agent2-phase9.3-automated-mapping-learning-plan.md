# Phase 9.3 — Automated Mapping & Learning

**Objective**: Self-improving column mapping system that learns from user corrections.

## Dependencies

- Existing `SmartImportMapper`, `SmartImportMapping` engines
- Phase 9.1 stores

## Implementation Tasks

### 1. Advanced Mapping Engine (src/engines/GLMappingEngine.ts)

- Pattern-based auto-detection (enhance existing SmartImportMapper)
- ML-light: tf-idf weighting on header tokens
- Fuzzy matching with Levenshtein distance
- Confidence scoring with threshold gating
- Cross-source mapping consistency

### 2. Learning Service (src/services/MappingLearningService.ts)

- Store user corrections (per user, per source system)
- Frequency-weighted preference boosting
- Collaborative patterns (same ERP → same mapping)
- Export/import mapping templates

### 3. Mapping Template Manager (src/components/data/MappingTemplateManager.tsx)

- Save/load named mapping templates
- Share templates across users
- Version history for templates
- Quick-apply with one click

### 4. Account Resolution UI (src/components/data/AccountResolver.tsx)

- Fuzzy account name → code resolution
- Suggest matches with confidence display
- Manual override with audit trail
- Bulk resolve remaining unmapped

## Verification

- Mapping accuracy > 90% on known ERP patterns
- Learning persists across sessions
- Template save/load roundtrip works
