# Phase 10.3 — Chart & Visualization Builder

**Objective**: Interactive chart builder with Recharts, multi-chart dashboards, and annotations.

## Dependencies

- Existing `ChartAnnotationEngine`, `DashboardBuilderEngine`
- Phase 10.1 grid, 10.2 OLAP

## Implementation Tasks

### 1. Chart Builder UI (src/components/spreadsheet/ChartBuilder.tsx)

- Chart type picker (bar, line, area, pie, scatter, waterfall, combo)
- Data source selector (grid range, cube query)
- Axis configuration (X/Y, secondary axis)
- Series configuration (color, style, stack)
- Chart preview with live updates
- Quick-insert into dashboard

### 2. Chart Annotations & Labels

- Data labels with formatting options
- Trend lines (linear, moving average)
- Reference lines (target, benchmark)
- Annotation text boxes
- Marker highlights for outliers

### 3. Dashboard Builder (src/components/spreadsheet/DashboardBuilder.tsx)

- Drag-and-drop chart layout
- Resizable/movable chart containers
- Linked filters across charts (click-to-filter)
- Auto-refresh on data change
- Dashboard themes and branding
- Export as image/PDF

### 4. Waterfall Chart Component

- Native waterfall chart for bridge analysis
- Intermediate subtotals support
- Custom color mapping (up/down/total)
- Data label formatting
- Drill-down from waterfall bars

## Verification

- All chart types render correctly
- Waterfall chart calculates intermediate totals
- Dashboard filters propagate to linked charts
- Chart exports as image without errors
