# Phase 9.4 — Large File Streaming Import

**Objective**: Handle >100MB files via chunked streaming with progress and memory safety.

## Dependencies

- Existing `StreamImportEngine`
- Phase 9.1 stores, 9.2 validation

## Implementation Tasks

### 1. Chunked File Reader (src/services/ChunkedFileReader.ts)

- Web Worker-based chunked reading
- Backpressure handling for memory-bound devices
- Auto-resume on failure
- Progress events per chunk

### 2. Web Worker (src/workers/importWorker.ts)

- Offload parsing to worker thread
- Row-by-row validation in worker
- Post validated chunks to main thread
- Transferable objects for zero-copy

### 3. Memory Monitor (src/services/ImportMemoryMonitor.ts)

- Track import memory usage
- Auto-pause if near limit
- Suggest smaller chunk sizes
- Fallback to minimal mode for low-memory

### 4. Progress UI (src/components/data/ImportProgressPanel.tsx)

- Real-time progress bar
- Row count / estimated time
- Error count with live updates
- Pause/resume/cancel controls
- Estimated time remaining

## Verification

- 200MB CSV imports without OOM
- Worker-based parsing doesn't block UI
- Progress updates at least every 1000 rows
