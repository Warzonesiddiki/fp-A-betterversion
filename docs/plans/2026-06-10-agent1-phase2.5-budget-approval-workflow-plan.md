# Phase 2.5 — Budget Approval Workflow

## Objective
Implement multi-stage budget approval workflow — submit, review, approve/reject, with audit trail and notifications.

## Current State
- `WorkflowEngine.ts` exists in engine registry
- No visible approval UI in components
- RBACEngine exists for authorization

## Work Units
| # | Task | Effort |
|---|------|--------|
| 1 | Design approval state machine (draft → submitted → in-review → approved/rejected) | 1h |
| 2 | Implement WorkflowEngine states + transitions | 3h |
| 3 | Build approval UI: submit button, approval card, comments | 4h |
| 4 | Add audit trail (who approved, when, comments) | 2h |
| 5 | Add email/in-app notification on status change | 2h |
| 6 | Add RBAC guards (who can approve, who can submit) | 2h |

## Acceptance Criteria
- Full state machine with guard conditions
- Approval/rejection requires comment
- Audit trail is immutable and timestamped
- Notifications fire on all transitions
