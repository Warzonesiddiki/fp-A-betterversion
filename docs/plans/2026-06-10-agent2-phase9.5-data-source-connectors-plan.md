# Phase 9.5 — Data Source Connectors

**Objective**: Connect to external data sources (ERP APIs, cloud storage, database imports).

## Dependencies
- Existing `ConnectorEngine`
- Phases 9.1-9.4

## Implementation Tasks

### 1. Connector Framework (src/services/connectors/ConnectorFramework.ts)
- Plugin-based connector architecture
- Authentication manager (OAuth2, API key, basic auth)
- Rate limiting and retry logic
- Schema discovery
- Metadata extraction (source, timestamp, version)

### 2. ERP Connectors
- SAP: OData/RFC via REST bridge
- Oracle NetSuite: SuiteScript API
- Microsoft Dynamics: OData
- Sage Intacct: Web Services API

### 3. Cloud Storage Connectors
- SharePoint / OneDrive file picker
- Google Drive API integration
- Dropbox / Box connectors
- S3-compatible storage

### 4. Database Import
- Read-only query builder
- Connection string management (encrypted storage)
- Schema browser (tables, views, columns)
- Scheduled sync with change detection

### 5. Connector Configuration UI
- Connection form with test button
- Credential store (encrypted)
- Connector status dashboard
- Sync schedule configuration

## Verification
- Connect, authenticate, fetch test data
- Schedule sync runs on timer
- Credentials encrypted at rest
- Connector errors handled gracefully
