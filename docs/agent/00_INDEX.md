# 00 — Index and source-of-truth matrix

This handbook (`AGENTS.md` + `docs/agent/*`) is the only instruction set for
agents. It is deliberately short per file and long on precision. Each file
owns one concern. If two documents disagree, the one named in the matrix
below wins and the other must be fixed or archived.

## Superseded documents (historical; do not follow as instructions)

The repository carries 478 Markdown files from earlier iterations. They are
useful as archaeology and must not be read as plans. In particular:

- Root: `PLAN.md`, `MASTER_ROADMAP.md`, `PROJECT_BACKLOG.md`,
  `COMPLETION_TASKLIST_ZERO_COMPROMISE.md`, `FINAL_PROMPT.md`,
  `HANDOVER_PROMPT_*.md`, `MASTER HANDOVER PROMPT.txt`, `AUDIT_REPORT_V3*.md`,
  `OMEGA_DEEP_AUDIT_PASS.md`, `REMEDIATION_REPORT.md`, `GAP_LEDGER.md`,
  `ANALYSIS_AND_FIXES.md`, `knowledge.md`, `KANBAN.json`,
  `PROGRESS_TRACKER.html`, `finplan-ceo-remediation-status.html`,
  `README.legacy.md`.
- Directories: `_bmad/`, `agents/`, `plan/`, `prompt/`, `skills/`,
  `presentations/`, `MEMORY/`, `docs/*_PLAN*.md`, `docs/GAP_*.md`,
  `docs/STRATEGIC_*.md`, `docs/*ROADMAP*.md`, `docs/CONSTITUTION_v5.md`,
  `docs/ZERO_COMPROMISE_PRODUCT_BLUEPRINT.md`, `docs/COMPLETE_PROJECT_SPEC.md`.
- Any document that says the product is "feature complete", "100 % green",
  "100 % money safe" or "fully offline". Those claims were measured false on
  2026-10-15 (`docs/audit/…` §2).

Still useful references (not plans): `docs/ARCHITECTURE.md` (narrative,
partly stale), `docs/adr/ADR-00x` (real decisions on currency translation,
Zustand, cube, decimal.js, master storage, migrations), `docs/architecture/*`
(money, period-close, rbac, persistence map), `docs/TESTING.md`,
`docs/GLOSSARY.md`, `SECURITY.md`, `docs/security/`.

Archiving these physically is decision DEC-006 (owner). Until then, this
section is the archive boundary.

## Precedence when documents conflict

1. A script's measured output.
2. `AGENTS.md` / `docs/agent/`.
3. `docs/discovery/` (plan of record) and `docs/audit/`.
4. ADRs in `docs/adr/`.
5. Everything else — informational only.
