# Brainstorm Session: FinPlan Strategic Wedge

> **Facilitator:** Blaze · **Date:** 2026-08-10 · **Status:** DIRECTION SET — YOLO mode  
> **Decision:** What should FinPlan prove before attempting broad FP&A parity?

## Input context

Rex found broad competitors already own connected planning, close/consolidation, modern modeling, and AI messaging. FinPlan has strong breadth but no primary evidence that feature count or local-first alone wins enterprise procurement.

## Techniques

First-principles decomposition, Crazy 8s, impact/effort scoring, and pre-mortem.

## Divergent phase — all ideas generated

1. Build all 78 sector dashboards to dominate breadth.
2. Recreate Excel perfectly and market a desktop spreadsheet replacement.
3. Make a CFO decision workspace with signal → evidence → owner → action.
4. Become the controlled month-end close cockpit for multi-entity teams.
5. Build a local-first planning workspace with optional enterprise governance.
6. Focus on rapid SaaS planning/metrics and integrations.
7. Focus on manufacturing cost/driver planning and operational finance.
8. Sell a white-label engine/plugin platform to consultancies.
9. Build an AI financial analyst as the main product.
10. Build a report/board-pack evidence system first.
11. Focus on import/mapping/reconciliation as a data-quality control plane.
12. Build an implementation accelerator: templates, migration, controls, and reference data.

## Non-obvious combinations

- 3 + 4 + 10: Decision Workspace fed by a controlled Close Cockpit and published through evidence-backed board packs.
- 5 + 11 + 12: local analyst workspace with governed import/reconciliation and fast implementation.
- 3 + 9: cited AI assists the decision workspace but never becomes the product’s unsupported authority.

## The crazy idea

**Finance Evidence Graph:** Every number behaves as a navigable object linking transaction, source, formula, assumption, approval, exception, and board narrative. Steelman: this could become a differentiated trust layer across close, planning, reporting, and AI. Risk: graph scope can become an expensive platform detour. Decision: implement a narrow evidence drawer/snapshot lineage first, not a graph database program.

### Pre-mortem — recommended combination

| Failure mode | Early signal | Countermeasure |
|---|---|---|
| Close scope becomes endless | pilot asks for every ERP/GAAP/FX case | define one ICP and controlled pilot data contract |
| Decision Workspace is another dashboard | users still export to slides | require evidence/action completion usability test |
| Governance slows analysts | analysts bypass system for Excel | keyboard/paste/model speed benchmarks and guided migration |
| Local-first blocks IT | security review rejects device/cache model | security questionnaire before architecture commitment |

## Ranked shortlist

1. **Controlled close-to-decision-to-board-pack loop** — strongest combined credibility, urgency, and observable customer outcome.
2. **Implementation accelerator plus governed import/reconciliation** — fastest path to trusted inputs and time-to-value.
3. **Local-first governed analyst workspace** — differentiated only if A-02 is validated by target buyers.

## Discarded/deferred ideas

- Sector breadth: no evidence it creates deep buyer value.
- AI-first: trust and adoption evidence argues for assisted/cited AI.
- Generic dashboard redesign: insufficient without evidence/action loop.

## Direction

Build and research toward the **controlled close-to-decision-to-board-pack wedge**, with Atlas as the UX foundation and the analyst workspace as enabling capability. Local-first remains a conditional strategic option, not the primary selling claim until validated.

## Open questions

- Select ICP, design partners, first connector, and pilot vertical.
- Validate willingness to pay and deployment preference before finalizing packaging.
