## Priority order

1. Validate ICP, economic urgency, deployment preference, and core workflow through primary research.
2. Convert the controlled close-to-decision-to-board-pack contracts into a research-backed PRD/UX/architecture.
3. Validate the dedicated AI, sync, consolidation/FX, vertical-certification, and commercial/implementation contracts with target stakeholders.
4. Rebaseline PRD, UX, architecture, and stories only after evidence changes assumption status.
5. Implement only the validated pilot vertical slice.

## Rule

A green row means a documented hypothesis exists—not that the capability is shipped, connected, governed, or enterprise-ready. The Capability Truth Matrix remains the implementation maturity source of truth.
