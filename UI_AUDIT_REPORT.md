# Industry Dashboard UI Audit Report

**Date:** 2025-03-24
**Subject:** Consistency Audit for Industries Dashboards (SaaS, Manufacturing, Retail, Banking, Healthcare, Energy, ESG)

## Executive Summary
The industries dashboard suite shows significant divergence in implementation fidelity. While **Retail**, **Banking**, and **Energy** dashboards are near production-ready with domain-specific charts and KPIs, the **SaaS**, **Manufacturing**, **Healthcare**, and **ESG** pages are currently low-fidelity boilerplate templates that show standard GL account lists.

## Audit Findings by Industry

### 1. SaaS, Manufacturing, Healthcare, ESG (Score: 2/4)
- **Issue**: These pages are "clones" of each other. They provide no industry-specific value beyond a generic GL list.
- **Copy**: Generic placeholder text for empty states.
- **Visuals**: No charts or trends implemented.

### 2. Retail & Energy (Score: 3.5/4)
- **Visuals**: Excellent. Use of Recharts `AreaChart` and `BarChart` provides high value.
- **Color**: Uses `#16A34A` and `#DC2626` correctly for growth metrics, but hex codes are hardcoded in chart components.
- **Typography**: Uses `text-3xl font-black` for high-impact headings.

### 3. Banking (Score: 3/4)
- **Experience**: Strong domain alignment (NIM, Capital Adequacy).
- **Color**: Lacks variance coloring in some areas where it would be expected (e.g., NPL ratio status).

## Cross-Cutting Issues

### Variance Coloring
- **Requirement**: Use `#16A34A` (Favorable) and `#DC2626` (Unfavorable).
- **Status**: Most pages use Tailwind `text-green-600` and `text-red-600` which maps to these hexes. However, some pages (AI/Audit) use `green-400` or `green-500`, creating a visual mismatch.

### Spacing & Typography
- **Consistency**: High. Most pages use `p-6` and `space-y-6`.
- **Typography**: Headings are consistent across the suite.
- **Observation**: Tabular figures (tabular-nums) are not consistently applied to financial tables, making them harder to read in a native desktop app context.

## Actionable Recommendations

1. **Sync Dashboard Fidelity**: Upgrade SaaS, Manufacturing, and Healthcare dashboards to match the Retail/Energy UI patterns (add charts, specific KPIs).
2. **Eliminate Hardcoded Colors**: Replace hex strings in Recharts components with CSS variables or tokens from `designTokens.ts`.
3. **Semantic CSS Classes**: Introduce `.fin-positive` and `.fin-negative` classes to encapsulate the `#16A34A` and `#DC2626` colors, rather than relying on raw Tailwind classes that can easily drift.
4. **Desktop Optimization**: Apply `tabular-nums` to all `DataTable` numeric columns to provide the "Native Financial App" feel requested by the user.
