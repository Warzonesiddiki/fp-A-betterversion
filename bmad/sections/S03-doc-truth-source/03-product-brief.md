# S03 — Product Brief

**Date:** 2026-07-25

## 1. Vision
Every document has one clear job; status is honest and centralized.

## 2. Target Users
- Developers, agents, auditors, users evaluating the product.

## 3. Problem & Value
- Problem: contradictory docs make the project look done when it isn't.
- Value: trustworthy docs → correct decisions in S04–S100.

## 4. Success Metrics
- README status accurate; `DOCS_MAP.md` exists; no two docs claim conflicting status.

## 5. Scope Guardrails
- In: DOCS_MAP, README fix, prune reports, quarantine doc-scratches.
- Out: rewriting all docs (only status-critical ones touched).
