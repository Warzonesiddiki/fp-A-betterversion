# S06 — Product Brief

**Date:** 2026-07-25

## 1. Vision
One token system powering a consistent, themeable, accessible UI in both modes.

## 2. Target Users
- End users (theme/accent), developers (single source).

## 3. Problem & Value
- Problem: scattered colors → inconsistent, dark-mode broken in places.
- Value: consistent theming; enables S88 audit.

## 4. Success Metrics
- All new components use tokens; accent switchable; dark/light via tokens.

## 5. Scope Guardrails
- In: token files + Tailwind theme + accent.
- Out: auditing existing raw colors (→ S88).
