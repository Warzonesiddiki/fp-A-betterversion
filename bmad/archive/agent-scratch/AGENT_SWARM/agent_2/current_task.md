# Task P0-05: Write Engine Tests

**Objective:** Write comprehensive unit tests for `ConsolidationEngine`, `MultiCurrencyEngine`, `TaxEngine`, and `ScenarioEngine`.

**Plan:**

1.  **Locate Engines:** Identify the source files for the four specified engines within the `src/engines/` directory.
2.  **Create Test Files:** For each engine, create a new test file with a `.test.ts` suffix (e.g., `ConsolidationEngine.test.ts`).
3.  **Analyze Logic:** Review the source code of each engine to understand its functionality, inputs, outputs, and the mathematical logic involved.
4.  **Write Tests:** Develop a suite of tests for each engine to verify:
    *   **Correctness:** Ensure the core calculations are accurate.
    *   **Edge Cases:** Test with zero values, negative numbers, empty arrays, and other boundary conditions.
    *   **Scenarios:** Cover different configurations and use cases.
5.  **Verification:** Run all tests and ensure they pass.
6.  **Finalize:** Once all tests for the four engines are written and passing, the task will be complete.
