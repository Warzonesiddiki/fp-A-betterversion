# PRODUCT/USERS

Personas named by the Codex and blueprint (Section 2 of `.agent/BLUEPRINT.md`, which also sets
per-persona onboarding time targets):

| Persona | Job to be done |
| --- | --- |
| CFO / finance leader | Trustworthy board-ready numbers, fast close commentary, scenario answers in a meeting |
| FP&A analyst | Build and reforecast driver-based models without exporting to Excel |
| Controller | Close tracking, variance explanation, audit trail |
| Operator / budget owner | Own a cost centre budget, see actuals vs plan, submit changes |
| Auditor / reviewer | Trace any displayed figure back to posted ledger entries |

Cross-cutting requirement for all of them: **every figure must be traceable to the GL, or shown as
unavailable.** That is what W0.1.1 is buying.
