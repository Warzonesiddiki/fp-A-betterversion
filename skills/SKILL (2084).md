# Customer Segmentation

## Skill Overview
This skill enables AI assistants to perform customer segmentation analysis, dividing customer bases into meaningful groups based on behavior, demographics, and characteristics for targeted marketing.

## MCP Servers to Use
- posthog - Behavioral cohort analysis
- mplitude - User segmentation and cohort analysis
- google-analytics - Audience segmentation data
- phoenix - ML-powered analytics for segmentation

## Capabilities
- Analyze customer behavior patterns
- Create behavioral and demographic segments
- Identify high-value customer cohorts
- Track segment performance over time
- Generate segment-specific insights
- Build predictive customer models
- Enable personalized marketing by segment
