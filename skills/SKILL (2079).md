# Design System Development

## Overview
Create, maintain, and evolve comprehensive design systems with consistent visual language and component libraries.

## Trigger
- /design-system - Start design system development workflow

## Capabilities

### System Architecture
- Define design tokens (colors, typography, spacing, shadows)
- Create component hierarchy and naming conventions
- Establish states, variants, and prop interfaces
- Document usage guidelines and best practices

### Token Management
- Organize tokens by category (primitive, semantic, component)
- Export tokens in multiple formats (CSS, SCSS, JSON, JS)
- Sync tokens between design tools (Figma) and code
- Version control and migration strategies

### Component Library
- Build reusable UI components with consistent API patterns
- Implement accessibility features (ARIA, keyboard navigation)
- Create responsive variants for all breakpoints
- Document props, slots, and usage examples

### Documentation
- Generate living documentation from component code
- Create interactive examples and playrooms
- Document design decisions and rationale
- Maintain changelog and migration guides

### MCP Tools for Design Systems
- prompt-to-asset - Generate logos, icons, and brand assets
- decantr - Design intelligence and governance for AI-generated UI
- igma-chunked - Extract and organize large design files

## Design System Layers

1. **Foundation**: Colors, typography, spacing, icons
2. **Patterns**: Layouts, forms, navigation patterns
3. **Components**: Atomic and molecular UI elements
4. **Templates**: Page-level patterns and layouts
5. **Applications**: Complete design solutions

## Workflow Steps

1. **Audit**: Review existing designs and identify patterns
2. **Define**: Create token taxonomy and component inventory
3. **Build**: Develop component library with documentation
4. **Validate**: Test consistency and accessibility compliance
5. **Publish**: Release and distribute design system
6. **Maintain**: Plan updates and handle feedback

## Usage Examples
- /design-system audit - Analyze current design consistency
- /design-system create [name] - Initialize new design system
- /design-system tokens - Export design tokens

## Requirements
- Clear understanding of brand and product requirements
- Access to design tools (Figma, Sketch)
- Component development framework (React, Vue, etc.)
