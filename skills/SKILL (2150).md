# UX Research Methodology

## Overview
Conduct rigorous user experience research to inform design decisions and validate product assumptions with real user data.

## Trigger
- /ux-research - Start UX research project

## Capabilities

### Research Planning
- Define research objectives and questions
- Identify target user segments
- Create research timeline and budget
- Select appropriate methodologies
- Recruit participants

### Research Methods

#### Discovery Research
- Stakeholder interviews
- Competitive analysis
- Contextual inquiry
- Diary studies
- Cultural probes

#### Generative Research
- User interviews
- Focus groups
- Surveys and questionnaires
- Card sorting
- Tree testing

#### Evaluative Research
- Usability testing (moderated/unmoderated)
- A/B testing
- Accessibility audits
- Heuristic evaluation
- Cognitive walkthrough

#### Continuous Research
- Analytics review
- Session recordings
- Feature feedback loops
- Sentiment analysis

### Data Analysis
- Thematic analysis
- Affinity mapping
- Journey mapping
- Persona development
- Jobs-to-be-done framework
- Quantitative statistical analysis

### Research Outputs
- Research reports
- Journey maps
- Personas and archetypes
- User quotes and videos
- Recommendations and优先级 matrix
- Design guidelines

### MCP Tools for UX Research
- obsidian - Note-taking and synthesis
- llm-wiki - Knowledge base management

## Research Framework

### Define Phase
1. Business goals alignment
2. Research questions formulation
3. Success metrics definition

### Plan Phase
1. Methodology selection
2. Participant recruitment
3. Discussion guide creation
4. Ethics and consent preparation

### Conduct Phase
1. Pilot testing
2. Data collection
3. Real-time note-taking
4. Immediate insights capture

### Analyze Phase
1. Transcription and organization
2. Theme identification
3. Pattern recognition
4. Insight synthesis

### Share Phase
1. Stakeholder presentation
2. Research report
3. Design recommendations
4. Action items

## Common Research Setups

### Usability Test
- 5-8 participants for qualitative
- Task completion metrics
- Time on task measurement
- Error rates
- SUS (System Usability Scale)
- Think-aloud protocol

### User Interview
- 30-60 minute sessions
- Semi-structured format
- Open-ended questions
- Scenario-based prompts
- Environment observation

### Survey
- Clear questionnaire design
- Mix of question types
- Appropriate sample size
- Statistical significance
- Bias prevention

## Research Ethics
- Informed consent
- Data privacy (GDPR, CCPA)
- Participant compensation
- Voluntary participation
- Anonymity protection
