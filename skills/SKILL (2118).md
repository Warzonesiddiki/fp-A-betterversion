# Google Analytics Integration

## Skill Overview
This skill enables AI assistants to integrate with Google Analytics 4 (GA4) via MCP servers, providing natural language access to website traffic data, user behavior metrics, and conversion tracking.

## MCP Servers to Use
- google-analytics (2.1k stars) - Integrates Google Analytics APIs with local MCP server
- google-analytics-2 (207 stars) - Connects GA4 data with 200+ dimensions/metrics
- google-analytics-5 - LLM-consumable analytics tools
- ga4 - Direct GA4 data retrieval for website/app performance

## Capabilities
- Query website traffic and user behavior data
- Access 200+ GA4 dimensions and metrics via natural language
- Retrieve real-time analytics data
- Generate traffic reports and insights
- Analyze user acquisition channels
- Track conversion events and goals
- Export data for further analysis

## Trigger Phrases
- analyze google analytics
- get GA4 traffic data
- user behavior metrics
- conversion tracking
- website analytics report
