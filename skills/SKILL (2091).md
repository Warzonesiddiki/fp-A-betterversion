# Calendar Integration Patterns Skill

## Overview
This skill enables cross-platform calendar integration, scheduling automation, and calendar management across multiple providers through MCP.

## MCP Market Research
MCP Market research shows integrations available for:
- Google Calendar (via Google Workspace MCP - 2.4k installs)
- Outlook Calendar (via Microsoft Graph)
- Cal.com and Calendly for scheduling
- iCal feed aggregation

## Capabilities

### Multi-Provider Support
- Google Calendar integration
- Microsoft Outlook/Exchange support
- Cal.com and Calendly APIs
- iCal feed parsing

### Event Management
- Create, update, and delete events
- Handle recurring events
- Manage attendees and RSVPs
- Configure event reminders

### Scheduling Automation
- Find available time slots
- Coordinate across calendars
- Handle time zone conversions
- Book meetings automatically

## Integration Points
- Google Calendar API
- Microsoft Graph API (Calendar)
- Cal.com API
- Webhook handlers for updates

## Use Cases
1. Cross-calendar Scheduling - Find optimal meeting times
2. Meeting Coordination - Sync across team calendars
3. Availability Management - Handle working hours
4. Event Aggregation - Unified calendar views
5. Reminder Automation - Multi-channel notifications

## Trigger Phrases
- find-available-slot
- create-calendar-event
- sync-calendars
- schedule-meeting
