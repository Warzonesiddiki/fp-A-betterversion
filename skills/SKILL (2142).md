# Skill Creator

## Overview
This skill provides guidance for creating and publishing new MCP skills to the marketplace.

## Capabilities

### Skill Structure
- Define skill metadata and naming conventions
- Create SKILL.md with proper YAML frontmatter
- Organize skill files and resources
- Document capabilities and trigger phrases

### MCP Market Integration
- Research existing skills for patterns
- Define proper trigger phrases
- Add MCP server references
- Include usage examples

### Documentation
- Write clear skill overviews
- Document all capabilities
- Provide code examples
- Add related skills references

## Trigger Phrases
- create-skill
- new-skill
- skill-template
