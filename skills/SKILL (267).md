# Frontend Design Skill

Apply when: building UI components, designing layouts, creating landing pages, working on responsive design.

## Principles
- Mobile-first responsive design
- Consistent spacing scale (4px grid)
- Visual hierarchy through typography and color
- Accessibility (WCAG 2.1 AA minimum)
- Component composition over inheritance

## Patterns
- Atomic design: atoms → molecules → organisms → templates → pages
- Container/presentational split
- Render props and compound components
- Controlled vs uncontrolled components

## Checklist
- [ ] Responsive at 320px, 768px, 1024px, 1440px
- [ ] Keyboard navigable
- [ ] Color contrast ratio ≥ 4.5:1
- [ ] Loading and error states handled
- [ ] No layout shift (CLS < 0.1)
