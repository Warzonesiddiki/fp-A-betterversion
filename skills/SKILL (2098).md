# Antigravity Integration

Integrate with Google Antigravity AI services and workspace capabilities, enabling cloud operations, multi-agent orchestration, and enhanced productivity workflows.

## Core Capabilities

- **Cloud Operations**: Leverage Antigravity for scalable cloud tasks
- **Workspace Integration**: Connect to Antigravity IDE sessions and mobile devices
- **Multi-Agent Coordination**: Orchestrate multiple AI agents with isolated capabilities
- **Notebook Integration**: Read, edit, and execute Jupyter notebooks within Antigravity
- **Memory Persistence**: Use agent-memory-mcp for institutional knowledge

## Antigravity MCP Servers

- **Antigravity Workspace**: Transform codebases into queryable AI assistants
- **Antigravity Link**: Connect IDE sessions to mobile devices for enhanced interaction
- **Antigravity Optimizer**: Navigate and optimize large codebases using local RAG
- **Antigravity Agent**: Orchestrate AI interactions with isolated capabilities
- **Solve Runner**: Multi-round collaboration between AI agents

## Usage

Invoke via `/antigravity-integration` when:
- Needing cloud-scale AI operations
- Coordinating multi-agent workflows
- Accessing persistent workspace memory
- Performing large-scale code analysis with RAG
- Managing complex full-stack development tasks

## Workflow Patterns

1. **Task Complexity Evaluation**: Determine when Antigravity is required
2. **Skill Discovery**: Find appropriate tools from master catalog
3. **Agent Orchestration**: Coordinate multiple specialized agents
4. **Memory Integration**: Leverage agent-memory-mcp for persistence
5. **Result Synthesis**: Combine outputs from multiple agents

## Best Practices

- Use Antigravity for complex, multi-domain tasks
- Leverage RAG-based optimization for large codebases
- Implement guardrails for baseline capabilities
- Track successful skill combinations for reuse
- Enable cross-platform synchronization via Antigravity Link
